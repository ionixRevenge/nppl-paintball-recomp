# Put your ISO here

Place **your own** dump of *NPPL Championship Paintball 2009* (USA, `SLUS-21855`) in this folder as a `.iso` file.
Any filename works. BIN/CUE, CHD and CSO images must be converted to ISO first.

Known-good dump SHA-1: `8db77412f8d920d6b742269deb8c5c0ec7b5e4f1`

This project does not include or distribute any game content. Nothing in this folder is ever committed.
